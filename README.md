# SHIKAYAMA!ニュース

鹿山通り商店街の身内ジョークを、ニュースポータル＋週刊誌（飛ばし記事・陰謀論）風に楽しむ静的サイトです。Yahoo! JAPANの公式サイトではありません。記事・証言・数字・生成画像はすべて創作です。

## ファイル

- `index.html`: HTML、CSS、JavaScriptをまとめたメインページ
- `assets/`: 記事で使う画像
  - `press-conference.png`: 福井氏の会見画像
  - `succession.png`: 辞任表明と後任内定（堀将二氏）のニュース画像
  - `four-resignations.png`: 4人の引責辞任画像
  - `weekly-shikayama.png`: 週刊鹿山・秋の増刊号の中吊り広告
  - `thumbs/`: 記事一覧用のサムネイル（各人物の顔・椅子を切り出したもの）

`index.html`をブラウザで開くと、ローカルでも閲覧できます。`assets`フォルダは`index.html`と同じ階層に置いてください。

## 機能

記事の閲覧、人物名・本文検索、カテゴリ切り替え、記事の保存、ローカル保存のコメント、記事リンクのコピー、週刊誌画像の拡大。保存情報とコメントは、閲覧中のブラウザのlocalStorage（`shikayama-*`）にだけ保存されます。

## 編集のしかた

記事は`index.html`内の`articles`配列にまとまっています。本文の要素は、文字列（段落）、`{h:'見出し'}`、`{quote:'引用'}`、`{list:['項目', ...]}`の4種類です。
